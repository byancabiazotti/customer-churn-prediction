# Previsão de Churn de Clientes

## Objetivo
Analisar dados de clientes de telecomunicação para identificar padrões de cancelamento (churn).

## Dataset
Telco Customer Churn Dataset (Kaggle)

## Ferramentas Utilizadas
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Análises Realizadas
- Carregamento dos dados
- Verificação da estrutura do dataset
- Estatísticas descritivas
- Análise da quantidade de clientes que cancelaram
- Visualização gráfica do churn

## Principais Insights
- 5.174 clientes permaneceram
- 1.869 clientes cancelaram
- Taxa de churn aproximada de 26,5%
